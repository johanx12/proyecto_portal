# Plan de mejora

1. Recuperación de cuenta, verificación de correo y límite de intentos.
2. Alojamiento continuo con HTTPS, logs y monitoreo para disponibilidad real.
3. Respaldo automático y simulacro de restauración.
4. Notificación de respuesta por correo.
5. Reporte programado y cierre mensual inmutable.
6. Asignación de agentes, prioridades y tiempos de atención.
7. Adjuntos con límites y validación.
8. Migración a PostgreSQL y pruebas de concurrencia.

Cada fase debe tener pruebas y una persona responsable. La IA y el chat en vivo pueden evaluarse después de validar el flujo básico, con datos mínimos y permisos claros.
